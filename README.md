# 面试训练场

一个本地优先、面向实习/校招和初级工程师的 Java 后端与 AI / Agent 面试训练网站。

当前题库包含 **985 道题**：725 道 Java 后端题（12 个同级专题、145 个知识点）和 260 道 AI / Agent 应用开发题。每个知识点都拆成概念定义、原理机制、项目应用、故障排查、对比选型五类问法，并提供新手讲解、回答结构、来源和学习入口。

项目不要求账号或数据库，不上传学习记录，不绑定模型厂商，默认只监听本机 `127.0.0.1`。Node.js 20+ 即可运行，默认构建没有第三方运行依赖。

## 30 秒启动

### Windows 10/11 x64 免安装版

从 [Releases](https://github.com/Victorica123/interview-trainer/releases/latest) 下载 `interview-trainer-windows-x64-v0.5.0.zip`，完整解压后双击 `start.bat`。它内置经过官方 SHA-256 校验的 Node.js 运行时，无需安装依赖。

### 跨平台轻量版

下载 `interview-trainer-v0.5.0.zip`，并先安装 [Node.js 20 或更高版本](https://nodejs.org/)。项目没有第三方 npm 依赖，无需执行 `npm install`。

Windows 双击 `start.bat`；macOS / Linux 执行：

```bash
chmod +x start.sh
./start.sh
```

也可以在项目目录运行：

```bash
npm start
```

启动脚本会自动打开浏览器。服务默认使用 <http://127.0.0.1:4173>；如果端口已被占用，会依次尝试后续端口，并在终端显示和打开最终地址。也可以通过 `INTERVIEW_TRAINER_PORT` 指定起始端口。

## 推荐使用方式

1. 第一次使用先从“学习路线”选一个阶段，建立主线知识框架。
2. 在“题库训练”按专题、知识组、知识点、题型、层级或公司面经关联筛选。
3. 在“自定义题单”组合自己的目标。专题卡片可展开查看粗略题干、知识点、题型和答案摘要；“收入题单/候选题”标签会说明题量限制后的最终范围。
4. 先口述或写下答案，再打开精简答案与五段式讲解。按真实掌握程度标记 0–4，低分题会进入错题和复习队列。
5. 定期导出进度 JSON。浏览器数据按地址隔离，切换端口、`localhost`/`127.0.0.1`、浏览器或项目目录前建议先导出。

自定义题单保存的是固定题目 ID 快照，题库新增匹配题时不会静默改变训练范围；页面会提示是否由用户刷新。已有题目 ID 保持稳定，升级题库不会重编号旧进度。

## 题库覆盖与可信度

### 一眼看懂评分

每道题的基础重要度按下面的固定公式计算，最高 98 分：

```text
46 + 知识点优先级×4 + 题型奖励
   + 真实面经频次（≤16）
   + 公司/平台/候选阶段多样性（≤5）
   + 岗位与资料交叉验证（≤2）
   + 公开题库关注度（≤2）
```

| 信号 | 怎么使用 | 明确不会做什么 |
| --- | --- | --- |
| 近期直接面经 | 正文可核验、去重后进入频次与趋势，是主要动态信号 | 转载、聚合帖和一帖多题不会重复放大 |
| 公开题库标题 | 识别用户关注的知识点，单快照低置信，最多加 2 分 | 不访问 VIP 答案，不算面经次数，不单独创建新知识点 |
| 岗位、指南、官方文档 | 补齐目录并验证事实，最多提供 2 分交叉验证 | 不制造“近期高频” |

最终按分数分为核心必会（≥88）、高频主线（≥74）和完整备战。可选 AI 只能在公式基线的 ±6 分内复核并给出理由，不能绕过来源与数据校验。

### 当前覆盖

2026-08-29 的重筛审计对照了 JavaGuide、小林 coding 和面试鸭的公开目录/热门题库，并用公开牛客面经核对近期直接信号。Java 后端现有 145 个知识点，覆盖测试固定了 12 个专题中的 123 个主流目录必备检查项；每项必须保留五类问法，否则 `npm run verify` 会失败。

本次补齐的高频缺口包括：Java 21 虚拟线程、CompletableFuture、JIT/逃逸分析、Spring 事务传播与失效、InnoDB Buffer Pool、深分页、Redis Lua/Pipeline/跳表、TCP/UDP/TLS、系统调用与文件描述符、消息积压与死信、Kafka ISR/Rebalance/Exactly Once、RocketMQ 事务/延时消息、共识算法、API 网关、Transactional Outbox、容量估算、Nginx/CDN、Netty、设计模式、Docker 和 Elasticsearch。

重要限制：

- 题干和答案是按知识点重新组织的原创训练内容，不批量复制八股网站原文。

- 公开题库榜单/标题只表示用户关注度，单快照不宣称趋势，也不会提升面经样本数。

## 配置自己的 AI

打开左下角“AI 模型设置”，填写兼容服务的 Base URL、API Key 和精确模型 ID。若服务支持 `/models`，可以先测试并加载列表。

API Key 有三种明确状态：

- `仅本次运行`：只保留在当前 Node 进程内存，服务重启后消失。
- `跨重启保存`：明文写入本项目副本的 `.local/ai-config.json`，仅适合可信个人电脑。
- `无密钥`：未配置或已清除。

从持久态切换到会话态前页面会二次确认。浏览器和公开配置接口只得到 `saved` / `session` / `none` 状态，不会读回或打印明文 Key。`.local/` 已被 `.gitignore` 排除，发布包也必须通过显式白名单构建。

程序会自动拼接 `/v1/chat/completions`，也接受已经以 `/chat/completions` 结尾的地址。不同中转站若使用非标准字段，仍需按服务商文档调整。

## 更新题库

“更新题库”仅在配置 AI 后启用，会消耗对应服务额度。完整链路是：

```text
公开 Sitemap 增量发现 / 用户提供链接或正文
        ↓
主帖提取、URL/转载簇去重、本地已有知识点预筛
        ↓
低置信来源按约 8 篇批量 AI；证据句校验后再缓存
        ↓
可疑映射定向单篇复核；连续坏批次自动熔断
        ↓
新概念观察/晋级门槛 + 饱和频次评分
        ↓
持久化草案 → 用户审阅选择 → 正式校验
        ↓
原子应用 + 自动备份；需要时字节级回滚
```

自动发现只使用平台公开 Sitemap，不抓取牛客禁止的搜索页，也不绕过小红书限制。小红书 Sitemap 没有标题/日期，因此仍需用户明确链接或登录浏览器核验。牛客 `discuss` 与 `feed/main/detail` 两类入口会交错筛查，每轮最多从约 1.35 万个候选中收敛 300 篇面经；发现预筛缓存最多保存 3 万条并每 1000 页原子检查点，断网或取消后无需从头筛查。相同 URL、正文哈希和转载簇会去重；已知知识点尽量不调用 AI，未变化的第二次分析直接命中最多 5000 条 AI 分析缓存。

题库容量目标约 1000 题。数百篇样本主要更新来源、趋势、置信度和旧题排序；疑似新概念先进入观察池，达到近期独立来源与公司/平台多样性门槛后，每轮最多晋级 3 个概念，避免样本扩大十倍时题量也扩大十倍。AI 提取的每个知识点必须附带当前正文中的连续证据句；本地会校验证据归属和概念名称/同义标签，可疑映射只对该来源做单篇复核。连续 3 个批次仍不可用时自动熔断，剩余来源降级为单篇。更新报告会直接显示样本数、AI 调用数、证据通过/拦截、定向复核、熔断和容量预算。

牛客/小红书登录是可选能力。更新页会列出服务端实际探测到的浏览器：Chrome、Edge、Brave、Chromium 使用各自项目本地资料目录并可自动采集 Cookie；Firefox和系统默认浏览器只负责打开页面，需手动粘贴 Cookie。网页不能提交任意程序路径。Cookie 只保存在 `.local/site-cookies.json`，API 仅返回掩码状态，可随时清除。

## 隐私、安全与发布

- 服务默认只监听 `127.0.0.1`；当前版本不适合作为无鉴权公网服务直接部署。
- 学习进度只在浏览器 `localStorage`，AI Key、Cookie、缓存、草案和浏览器资料只在 `.local/`。
- 不要提交或打包 `.local/`、`data/*.json`、日志、浏览器 profile、缓存、backup 或 draft。
- 发布包应使用显式文件白名单，并在生成后检查归档条目；不要直接递归压缩整个项目目录。
- 外部网页正文和模型输出都视为不可信数据，必须经过规范化、边界限制、重新生成与校验后才能写入题库。

## 适合谁

适合希望用一套可追溯目录准备 Java 后端八股、需要自己组合专题题单，或想在本地接入模型辅助复习的人。

如果你需要 LeetCode/算法训练、前端题库、HR 行为面试、云同步/多人协作，或无需鉴权的公网 SaaS，本项目目前不覆盖这些场景。
