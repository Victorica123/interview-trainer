# 面试训练场 v0.5.0

本版本提供两种下载包：

- **Windows 10/11 x64 用户**：下载 `interview-trainer-windows-x64-v0.5.0.zip`。解压后双击 `start.bat`，无需另行安装 Node.js。
- **macOS、Linux 或已安装 Node.js 20+ 的用户**：下载 `interview-trainer-v0.5.0.zip`，按照 README 运行启动脚本。

请不要下载 GitHub 自动生成的 `Source code` 归档作为普通使用包。所有正式附件的 SHA-256 都记录在 `SHA256SUMS.txt`。
