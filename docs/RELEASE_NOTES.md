# 面试训练场 v0.6.0

本版本提供两种下载包：

- **Windows 10/11 x64 用户**：下载 `interview-trainer-windows-x64-v0.6.0.zip`。解压后双击 `start.bat`，无需另行安装 Node.js。
- **macOS、Linux 或已安装 Node.js 20+ 的用户**：下载 `interview-trainer-v0.6.0.zip`，按照 README 运行启动脚本。

请不要下载 GitHub 自动生成的 `Source code` 归档作为普通使用包。所有正式附件的 SHA-256 都记录在 `SHA256SUMS.txt`。

## 本次更新

- 全部 144 道 core 和 423 道 high 题完成显式、分题型内容复核；567 道题标记为已复核，418 道 extended 题继续诚实标记为提纲版。
- 43 个缺口主题新增可验证示例，现在 123 个 core/high 概念全部包含代码、命令、SQL 或伪代码，并提供核查来源。
- 新增 18 项 RFC、Linux、Java、Spring、RabbitMQ、OpenTelemetry、JSON Schema、Agent Skills、WHATWG 等官方资料或原始论文；总来源增至 422 项，学习资料仍不计入面经频率。
- 学习进度升级为 v4：可记录六类错因与最近 12 次作答，生成弱项诊断并一键开始最多 20 题的均衡专项训练；旧版 v2/v3 进度仍可导入。
- 题库更新器加入 10 条人工标注的合成抽取评测，覆盖正确映射、跨概念误映射、伪造/过短证据和部分有效结果。

- 更新器继续支持慢模型批处理、缓存、定向复核、失败熔断、部分结果提前收口、草案恢复、原子应用与字节级回滚。
