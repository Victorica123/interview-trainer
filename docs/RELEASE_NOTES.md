# 面试训练场 v0.7.0

本版本提供两种正式下载包：

- Windows 10/11 x64：`interview-trainer-windows-x64-v0.7.0.zip`，内置 Node.js，解压后双击 `start.bat`。

## 本次更新

- 学习进度升级为 v5：保留原有浏览器存储键，兼容 v2/v3/v4 导入，并新增稳定间隔、难度、遗忘次数和最近复习证据。
- 区分独立回答、提示后完成与看答案后复述；提示后最高按 3/4，答案展开后最高按 2/4，避免把熟悉感误记为掌握。
- 固定复习间隔升级为有界、自适应调度；连续独立回忆会延长稳定间隔，低分和遗忘会缩短间隔。
- AI 教练按评分点输出固定五段评价，并且每次只追问一个关键缺口；它能获知本轮是否使用提示或展开答案，但不能修改本地进度。
- 精修 65 道 importance 70–73、至少有两个独立面经样本的 extended 题；显式复核总数由 567 增至 632，其余 353 道继续标为提纲版。
- 为反射与注解、Java 序列化、一致性哈希、百万数据导入导出、高可用与容灾、Agent 记忆补齐可验证实践示例；增强概念总数增至 129。
